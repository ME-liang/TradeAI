## 输出要求（硬约束）

1. **只返回纯 JSON**，不要 markdown 代码块，不要任何解释性文字。
2. JSON 顶层固定 6 个键，键名必须完全一致：
   - `prof`：盈利能力解读
   - `growth`：成长性解读
   - `solv`：偿债能力解读
   - `eff`：运营效率解读
   - `bench`：行业对标解读
   - `fin`：财务速写（三表）解读
3. 每个值为**一段中文解读字符串**（2–4 句，约 40–80 字），聚焦该模块的核心结论与边际变化。
4. **只可使用数据包中给出的数字**，严禁编造或引用数据包之外的数据；某字段为「未获取」时直接说明该数据缺失，不臆测。
5. 结论须客观、基于数据，**避免使用「买入/卖出/推荐」等投资建议口吻**。
6. 风格专业、稳重、克制；结尾不重复附免责声明（由模板统一处理）。
